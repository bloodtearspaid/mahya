# Mahya Beauty — Static Splash Page

This package turns the supplied Mahya Beauty Hair Oil artwork into a lightweight,
responsive static splash page.

## Files

- `index.html` — responsive splash page
- `styles.css` — page styling
- `assets/mahya-hair-oil-splash.png` — full artwork
- `assets/brand-header.png` — top brand/header crop
- `assets/botanical-left.png` — left botanical crop
- `assets/botanical-right.png` — right botanical crop
- `assets/product-bottle.png` — bottle/product crop
- `assets/product-section.png` — central product section crop
- `assets/footer.png` — footer crop
- `assets/mahya-mark.png` — MH mark for favicon/branding

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static
file server. No build step, JavaScript, framework, or external dependency is
required.
